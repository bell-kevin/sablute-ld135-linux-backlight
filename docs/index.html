A default, without the daily chore

A small helper.
Then it gets out of your way.

The keyboard resets its backlight when it starts. This helper applies your preferred color at desktop login, so you don’t have to.

01

You sign in

A desktop autostart entry launches the helper. It waits up to 30 seconds for the matching keyboard.

02

The light turns white

It reads the current settings and sends a live lighting command, preserving the brightness field.

03

You take it from there

The helper exits. Use Fn + 2 whenever you want another color. Nothing keeps changing it back.

i

At graphical login. Your keyboard can show its factory color during computer startup and at the login screen. This helper doesn’t change the keyboard’s firmware or write to its EEPROM.

A specific fix, tested on a real keyboard

Made for this

Hardware names can hide different revisions. The helper checks both the USB identity and the exact HID report descriptor before sending a command.

One setup. A calmer start.

Make white your default.

Clone the source, install the system helper, then enable autostart for your own desktop account. No pip packages needed.

>_ Terminal
git clone https://github.com/bell-kevin/sablute-ld135-linux-backlight.git
cd sablute-ld135-linux-backlight
sudo python3 install_keyboard_white.py --system install
python3 install_keyboard_white.py --autostart enable

Run the last command as your regular user. The system step needs administrator access to install the helper and the rule for the matching HID interface.

Full installation guide ↗Preview either installer step with --dry-run.

Whenever you need it.

Set white immediately after installation:

ld135-white

At your next graphical login, the same helper runs automatically and exits.

The default is white. The rest of the day is up to you.

Easy to turn off.

From the cloned repository, disable the login entry. The manual command stays available.

python3 install_keyboard_white.py --autostart disable

Copy a command

Select the command text, then use your browser’s Copy action or press Ctrl + C (⌘ + C on macOS).
